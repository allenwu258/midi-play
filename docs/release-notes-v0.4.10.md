# MIDI Play v0.4.10

v0.4.10 在 v0.4.9 的基础上新增视频入场文字与交互预览。导出 MP4 时，可以在开头显示作品名称、词曲作者或演奏信息，分别调整标题和正文字号，拖动定位并预览整体退场效果。

## 主要更新

- **视频入场文字**：在“导出 → 视频”的参数列表中勾选“启用入场文字”，窗口自动加宽，右侧显示文字设置。文字从成品第 0 帧出现，与音乐同时开始，不延长视频或改变音乐起点。
- **标题与正文独立字号**：两个多行纯文本输入区分别设置字号，范围为 12–160 基准 px，默认标题 48、正文 32。可只填写标题或正文，空部分不占高度，也不会留下两段间距。
- **字体与可调描边**：两部分共用字体，保持白字黑描边；描边可通过滑块或数值框调整为 0.0–4.0 基准 px，默认 0.8，设置为 0 可关闭。字号与描边按 720p 参考画布随输出分辨率等比缩放。
- **对齐与定位**：支持文字内部左对齐、居中、右对齐，以及文字块整体居中、左下或自定义 X/Y 偏移。标题和正文作为一个整体移动，支持预览拖动、方向键微调，以及 Shift＋方向键每次移动 10 基准像素。
- **显示时间与退场效果**：分别设置完整显示时间和退场用时，可选择“淡出”或“向下滑出”；向下滑出时文字同时逐渐变淡。时长按成品视频计算，不随音乐播放倍率改变；动画超出片长时显示截断提示。
- **交互预览**：增加布局／拖动模式、无声播放／暂停、时间轴定位、回到开头、退场中点和消失后快捷按钮。预览与正式导出使用同一套文字排版和动画逻辑。

## 稳定性与交互改进

- 修复拖动文字时丢失鼠标释放事件、切换窗口或禁用控件后可能继续拖动的问题。
- 预览播放与输出路径校验分开，尚未选择导出文件或路径暂时无效时，仍可检查文字效果；开始导出时继续校验目标路径。
- 切换 30／60 FPS 时保留输出时间，并对齐到新帧率的最近一帧，避免预览时间跳变。
- 切换到音频页或隐藏导出窗口时停止预览并释放后台渲染与背景解码资源；重新打开时按最新配置恢复。
- 导出窗口按表单所需高度和屏幕可用区域调整，减少关键参数被挤出初始视区的情况；小屏保留滚动。未启用入场文字时，预览控制区保持可见并置灰，右侧设置收起。
- 文字内容或静态布局不合法时显示错误并阻止视频导出，保留原输入供调整；不静默截断内容、缩小字号或修改位置。

## 兼容性与使用

- Windows x64 便携版，随包部署 Qt、视频解码 DLL、插件和 MSVC 运行库；使用 Vulkan 仍需兼容的显卡及驱动。
- 视频导出仍需要 Vulkan 和外部 FFmpeg，可通过系统 PATH 提供或在设置中指定目录。FFmpeg 命令行工具不包含在发行包中；视频背景播放无需单独安装该命令行工具。
- 发行包不附带用户 SF2/SF3 音源或背景素材。乐曲播放和包含乐曲音频的导出仍需有效 SoundFont；不包含乐曲音频的 MP4 导出不要求配置 SoundFont。
- 入场文字默认关闭，仅作用于视频导出，不改变播放器主画面或 MP3/WAV 音频导出。v0.4.9 的视频背景及可选原声能力继续保留，视频背景仍为实验功能。

## 已知限制

- 入场文字使用纯文本，标题与正文共用字体、描边、对齐和动画，不支持富文本、独立颜色或多个自由文字块。
- 文字配置只保留为当前曲目的进程内草稿；取消对话框不覆盖已确认草稿，切换曲目或退出程序后不保留。
- 字体由本机提供，缺少字体时由 Qt 回退，跨机器不保证相同外观。短视频会截断超出片长的退场动画。
- 预览为无声预览。传统 Qt 图形模式支持实时播放与视频背景，但不支持视频导出；macOS 和 Linux 尚未建立同等完整的发行验证基线。

## 安装

1. 下载并将 `midi-play-v0.4.10-windows-x64.zip` 完整解压到独立文件夹。
2. 保持可执行文件、DLL、`platforms`、`multimedia` 等插件目录及许可证文件的相对位置不变。
3. 运行 `midi_play.exe`，按提示选择本地 SF2/SF3 音源。
4. 使用 MP4 视频导出前，启用 Vulkan 并配置外部 FFmpeg。
5. 打开乐曲，在“导出 → 视频”中启用入场文字，填写标题或正文，完成拖动与播放预览后开始导出。
