# 视频入场文字：架构与编码方案

状态：v0.4.10 已实现基础链路及标题／正文扩展。本文说明整体架构；双字号、可调描边的当前实现与验收边界见 [标题／正文与描边实现说明](intro-text-title-body-design.md)。

## 目标和交互契约

视频参数列表新增“入场文字”勾选项。默认关闭，保持原导出窗口的单列布局和 512×288 预览。启用后横向展开：左边保留视频参数和共享预览，右边展示文字编辑、样式、位置、时间和退场效果；取消勾选保留草稿并恢复紧凑窗口。切回音频页恢复紧凑尺寸。

初始窗口按完整视频参数所需高度增高，并限制在当前屏幕可用区域内；小屏或高 DPI 下保留滚动兜底。预览控制按钮、时间轴及时间说明始终显示，未启用入场文字或视频不可用时整体置灰禁用，启用文字后才展开右侧设置。

文字从成品第 0 帧出现，不延长视频、不改变音乐起点。完整显示和退场用时分开编辑。标题和正文分别支持多行纯文本与独立字号，共用字体、可调黑色描边、内部左/中/右对齐和文字块宽度；两段组合为一个整体，居中、左下或自定义中心偏移。白色文字自动换行，不自动缩小或截断输入。编辑尺寸以 1280×720 为基准，720p/1080p/4K 等比缩放。

布局模式显示第 0 帧和选中框，可拖动和方向键微调，位置同步到自定义 X/Y；时间模式隐藏编辑辅助线，支持播放/暂停、回到开头、时间轴、退场中点和消失后。预览无音频，背景与文字使用同一个输出帧时间。超出成品末帧的快捷点禁用；短片保留用户时长并提示动画会截断。

## 时间和渲染契约

输出时间 `t = frameIndex × 1,000,000 / fps`，仅背景音乐位置按导出倍率换算。保持 `S`、退出 `A` 均为成品时间：`t < S` 全显，`S ≤ t < S+A` 动画，之后不绘制。透明度为 `1 − u²(3−2u)`；滑出同时下移 `(H − top + 4) × u²`，裁剪边界为最终画布。

正式导出：配置预检 → 准备静态文字资产 → Vulkan 三槽渲染 → 按序回读 RGBA8888 → 文字合成 → 原编码队列 → 媒体校验 → 原子提交。关闭文字或动画已经结束时不创建 QPainter，不改变原回读/编码格式与帧数。第一版采用 CPU Alpha 合成，避免扩大 Vulkan shader 和资源生命周期改动；仅在文字存在的片头增加合成工作。

排版在固定逻辑画布上完成，使用 Qt 排版结果直接绘制，保留复杂文字塑形、双向文本、自动换行和字体回退。预览和成品仅栅格密度不同，不分别计算换行。位置调整复用静态文字图像。

## 预览并发和生命周期

后台线程独占 Vulkan 实例和背景解码器，最多一项进行中的任务和一个最新待处理请求。场景变更递增代次并取消旧场景，seek/开关递增预览版本；过期结果不可覆盖新状态。连续播放按单调时钟计算目标帧，慢机器跳过中间预览帧，但正式导出逐帧完整处理。接受背景帧时一起更新文字时点，禁止把新文字叠在旧时间的背景上。

视频页首次可见且可用时才启动后台会话；切换到音频页、隐藏窗口或禁用视频能力时立即取消请求并异步退出线程，释放 Vulkan 和解码资源。快速重新打开时只保留最新请求，等旧线程完成清理再启动新会话。取消标志由 worker 持有，保证其生命周期覆盖保留裸指针的背景解码器。页面销毁使用相同关闭流程，UI 不阻塞等待。

## 校验与兼容

启用但空白、超出字符/行数/字号/时间范围、静态块超出画布均阻止视频导出；关闭功能跳过文字校验。保留用户输入并显示错误，不静默截断。字体使用本机 Qt 字体回退，不承诺缺少字体时的跨机器外观一致。动画超出片长仅提醒，不延长成品。

同一曲目会话保存最近接受的文字配置，取消对话框不提交草稿，切曲清空。首版不新增持久项目格式、富文本、多文字块、入场淡入或音频试听。

## 实现步骤与验证范围

基础链路按以下步骤建立；这不是待执行的开发指令，也不代表所有视觉场景均已验收。当前验证结果与剩余项目见 [实现说明第 7 节](intro-text-title-body-design.md#7-验证记录与剩余验收)。

1. 建立配置、共享文字资产及几何/时间/像素测试。
2. 接入导出预检和回读后的合成，保持取消和提交语义。
3. 拆分右侧编辑面板和专用预览控件，接入拖动、键盘、自定义坐标。
4. 建立串行后台预览会话和播放/seek 状态机，接入窗口宽度切换。
5. 验证短片、倍率、30/60 FPS、分辨率缩放、关闭再开启、窗口销毁和非 Vulkan 构建。
6. 构建 GUI 与测试目标，运行现有视频配置测试、新增文字测试及真实 MP4 导出回读检查。发行构建通过项目 Windows SOP，并记录对应提交与测试结果。
