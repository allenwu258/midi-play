# MIDI Play · 落音

MIDI Play 的 Logo 设计素材。三根错落的方角音符条构成主图形，条形之间切出向右的播放箭头，将钢琴卷帘、音乐节奏和播放动作合为一个符号。

## 设计原则

- 保留播放器的方角音符特征，使用平直的边和清晰的留白。
- 以青绿、青蓝和柔蓝表达音乐的色彩感，不依赖发光、阴影或复杂渐变。
- 播放箭头为真正的透明镂空，随底色变化；单色使用时仍保留同一结构。
- 应用图标采用圆角底板，内部音符始终为方角。图标中的图形比独立标志放大 12%，便于小尺寸辨认。

## 文件选择

| 文件 | 用途 |
| --- | --- |
| `midiplay-preview.png` / `.svg` | 完整设计展示，包含深浅底、单色、应用图标和小尺寸效果 |
| `midiplay-mark.svg` | 主图形，透明背景，适用于深色底 |
| `midiplay-mark-light.svg` | 浅色底主图形，使用更深的同色系配色 |
| `midiplay-mark-ink.svg` / `midiplay-mark-white.svg` | 深墨色 / 白色单色主图形 |
| `midiplay-lockup.svg` | 图形与 MIDI Play 字标的横向组合，适用于深色底 |
| `midiplay-lockup-light.svg` | 浅色底横向组合 |
| `midiplay-icon.svg` / `midiplay-icon-light.svg` | 深色 / 浅色圆角底板应用图标 |
| `midiplay.ico` | Windows 多尺寸图标，包含 16、20、24、32、48、64、128、256 像素图层 |
| `png/` | 可直接使用的透明 PNG 与应用图标 |

`png/` 包含 1024 像素独立标志、2000 × 512 像素横向组合，以及 16、20、24、32、48、64、128、256、512、1024 像素深色应用图标。浅色应用图标另有 1024 像素 PNG，可从 SVG 导出其他尺寸。

| 角色 | 深色底版本 | 浅色底版本 |
| --- | --- | --- |
| 青绿 | `#49D6A4` | `#157653` |
| 青蓝 | `#39C5CE` | `#117F91` |
| 柔蓝 | `#719CEC` | `#456DCA` |
| 推荐底色 | `#121416` | `#F3F5F2` / 白色 |
| 字标 | `#F3F5F2` | `#202723` |

浅色底版本降低明度以增强轮廓辨识度，不建议将深色底的明亮配色直接替换进浅色组合。

## 使用规范

- 图形左右及上下至少保留半根音符条宽的留白。独立 SVG 的 512 × 512 画板已经包含安全留白。
- 保持纵横比，不拉伸、不旋转、不改变三根条形的顺序和间距，也不要将镂空箭头填成固定背景色。
- 独立标志建议使用 32 像素及以上；16～24 像素场景优先使用已导出的应用图标。微小尺寸以整体轮廓和三色识别为主。
- 深色背景使用主版或白色版；浅色背景使用浅色底版或深墨单色版。复杂背景上使用带底板的应用图标。
- 横向组合建议宽度不小于 160 像素；更小的空间只使用图形。
- 正式 Logo SVG 使用路径，不依赖外链、滤镜或字体。横向字标基于 Segoe UI Semibold 并已转为路径；展示板中的说明文字仍使用系统字体，固定展示效果请使用 PNG。

这些素材直接以 SVG 矢量图形制作。Windows 构建通过 `cmake/WindowsAppIcon.rc.in` 将 `midiplay.ico` 嵌入 GUI 可执行文件 `midi_play.exe`，用于资源管理器中的文件图标；无需在运行时分发外部 ICO。替换 ICO 后重新构建即可更新资源。

GUI 程序同时将同一份 ICO 编入 Qt 资源，在创建窗口前设置应用级 `windowIcon`，供原生标题栏、运行时任务栏和继承默认图标的窗口使用。程序内容区布局不变；CLI 不包含 Logo 资源。
